# khosomaty-public

Public assets for the **Khosomaty** Android app (`com.khosomatyegypt.app`).

This repository is public **on purpose**: GitHub Pages needs a public repository on
the Free plan, and Google Play requires a publicly reachable privacy-policy URL on
the store listing.

| file | what it is |
|---|---|
| `privacy-policy.html` | Privacy policy, Arabic + English |
| `terms.html` | Terms of service, Arabic + English |
| `index.html` | Landing page linking both |
| `ads/ad-free-trial-1080x608.webp` | Ad creative for the in-app carousel (16:9) |

Nothing here is a secret: no keys, no configuration, no source code.

Served at <https://remonshehata.github.io/khosomaty-public/>.
